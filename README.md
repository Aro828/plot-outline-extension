# 爽文大纲助手 (Plot Outline Assistant)

SillyTavern 第三方扩展。基于人物性格标签(《经典人物原型45种》)+ 情节类型(《经典情节20种》)
+ 世界书/MVU数值扫描,生成可手动编辑的粗纲/细纲,并可注入到对话上下文。

## 安装方法

### 方法一:直接复制到本地(最简单,适合手机酒馆App)

1. 找到你酒馆安装目录下的 `public/scripts/extensions/third-party/` 文件夹
   (如果用的是 SillyTavern-Launcher 或类似壳,一般路径是 `.../SillyTavern/public/scripts/extensions/third-party/`)
2. 把整个 `plot-outline-extension` 文件夹复制进去,保持文件夹名不变
3. 重启酒馆(或刷新网页/App),打开任意角色对话
4. 点开你截图里那个"小魔法棒"图标,菜单最下面能看到"爽文大纲助手"

### 方法二:通过 GitHub 安装(推荐,方便以后更新)

1. 在 GitHub 建一个新仓库,把这个文件夹里所有文件传上去(保持目录结构:
   `manifest.json`、`index.js`、`style.css`、`lib/*.json`、`README.md` 都在仓库根目录)
2. 在酒馆里:扩展面板(魔法棒图标)→ 右上角"安装扩展"按钮 → 粘贴你的仓库地址(格式类似
   `https://github.com/你的用户名/plot-outline-extension`)→ 安装
3. 安装完成后同样能在魔法棒菜单里看到入口

## 使用流程

1. **选中一个角色**,打开"爽文大纲助手"面板
2. 【人物标签】页:点"用AI提取标签",AI会基于人物设定推断1-2个主标签(原型)
   + 若干经历标签,也可以手动加自定义标签(总数上限10个,可在设置里调)
3. 【世界书扫描】页:点"开始扫描",自动识别角色卡/世界书里的规则句(防OOC)
   和数值(好感度/仇恨值等,兼容常见MVU写法),扫描结果可以手动核对修改
4. 【情节工具箱】页:勾选这段剧情想用的情节类型 + 爽点
5. 【大纲】页:填写剧情构想(可留空),点"生成粗纲"→ 每一幕都可以直接点文字编辑
   → 点"展开细纲"生成该幕的场景级表格(目标/阻碍/行动/结果/数值变化/伏笔/钩子),
   表格里的每一格也都能直接点击编辑
6. 编辑满意后点"注入到对话上下文",大纲摘要就会作为参考信息注入到之后的生成中
7. 【API设置】页:填写独立API(Claude 或 OpenAI兼容接口,包括DeepSeek等国产模型)
   的密钥、Base URL(仅OpenAI兼容需要)、模型名。这个API和酒馆本身连接的模型完全独立

## 关于标签库的扩充

`lib/archetypes.json`、`lib/plots.json`、`lib/shuang_dian.json` 三个文件就是你的标签库。
以后想加新书里的标签,直接在对应文件的 `custom_tags` / `custom_plots` / `custom_shuang_dian`
数组里按现有格式加条目就行,不需要改代码,刷新酒馆即可生效。

## 已知限制

- **世界书扫描**依赖 SillyTavern 内部API,不同版本暴露的接口可能不完全一致。
  如果扫描结果明显缺东西,大概率是你的酒馆版本世界书结构有差异,这种情况建议把
  规则句/数值相关的世界书条目手动粘到面板对应位置(后续可以加一个手动粘贴入口)。
- 大纲/标签数据存在酒馆本地设置里(`extension_settings`),换设备不会自动同步,
  不会导出成文件——这是按你的要求设计的。
- 悬浮窗为简易实现,拖动只支持鼠标(触屏拖动如果你主要用手机App,后续可以加触屏适配。)
